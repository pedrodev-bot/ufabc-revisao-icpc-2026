# Treinos Pré-ICPC — UFABC/GRUB

Material de nivelamento e revisão preparado pela comunidade para elevar o desempenho geral nas competições de programação, com foco na ICPC.

## Sobre o projeto

Este repositório reúne o conteúdo das aulas de revisão organizadas antes da ICPC: resumos de tópicos, exercícios sugeridos e materiais de apoio. A ideia é que qualquer pessoa — participante das aulas ou não — possa usar esse material para estudar por conta própria.

As aulas seguem um formato curto e prático (contextualização → resumo do tópico → casos específicos → direcionamento de estudos), pensado para destravar o raciocínio em pouco tempo, sem substituir o aprofundamento por conta de cada um.

## Estrutura do repositório

```
/aula-1-nivelamento     # fundamentos: sintaxe, estruturas de dados, interpretação
/materiais-apoio        # cheat sheets e conteúdo complementar
/exercicios             # listas de problemas sugeridas por tópico
```

## Como usar

- Cada pasta de aula contém o resumo do conteúdo e a lista de exercícios sugerida
- Os exercícios foram selecionados para serem resolvidos apenas com o conteúdo daquela aula + materiais de apoio indicados
- Dúvidas podem ser tiradas no canal [WhatsApp/Discord]
